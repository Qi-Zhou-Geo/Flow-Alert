## Major changes from 1.3 to 1.3.10
Compared with previous versions, including:
- version 1.0 (https://doi.org/10.5281/zenodo.15020368)
- version 1.1 (https://doi.org/10.5281/zenodo.16811121)
- version 1.2 (https://doi.org/10.5281/zenodo.16893616)
- version 1.3 (https://doi.org/10.5281/zenodo.18324322)
- the latest version 1.3.10 (same DOI as 1.3) includes the following major changes:

**(1) Docker:** A Docker image has been added to improve reproducibility. Due to its large size, the image is hosted on Zenodo.

**(2) Real-time deployment:** The [`functions/liveshow`](functions/liveshow) code has been added to support real-time Flow-Alert deployment in a Docker container on cloud servers such as AWS Lightsail.
